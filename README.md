# OLAF

OLAF is a mobile-first rental management application designed to help rental managers manage bookable facilities, customer reservations and cleaning operations.

The application provides a centralized place to manage facility availability, coordinate cleaning activities and monitor operational and financial performance.

## Technology stack

- **Backend:** C# / .NET 10
- **Web application:** ASP.NET Core Razor Pages
- **Dynamic interactions:** HTMX
- **Data access:** Entity Framework Core
- **Authentication:** ASP.NET Core Identity
- **Version control:** Git / GitHub

Database provider and hosting environment have not yet been selected.

## Project status

**Status: Planning and requirements clarification.**

Implementation has not started.

Business requirements and initial architecture are being clarified before development begins.
